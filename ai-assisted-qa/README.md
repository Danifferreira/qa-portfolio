# QA com apoio de IA

[English version](README.en.md)

Uso IA no dia a dia de QA para ganhar tempo no que é repetitivo e deixar o julgamento comigo. Esta pasta mostra as duas pontas disso.

| Onde | O que tem |
|---|---|
| [História para BDD](historia-para-bdd/) | Uma skill que transforma uma história de usuário em casos BDD no padrão deste repositório, com um exemplo real de entrada, o que a IA gerou e o que eu corrigi na revisão |
| [Como testo funcionalidades com IA e MCP](testando-ia-e-mcp.md) | Os riscos que priorizo e como testo cada um quando o produto tem IA dentro |

## Como uso a skill

Ela roda no Claude Code. Entrego a história com os critérios de aceite, ela devolve o Gherkin, uma tabela de rastreabilidade e as perguntas em aberto para produto. Eu reviso tudo antes de usar. A IA acelera o rascunho, mas quem decide o que é regra é produto, e quem decide o que vale testar sou eu.
